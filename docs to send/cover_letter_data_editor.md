Dear Data Editor,

Please find enclosed the replication archive for *A Tail of Labor Supply and a Tale of Monetary Policy*. The submitted package is `Replication_package_2Tails` and contains both the empirical and theoretical replication materials. The archive includes a master `README.md` at the package root, together with workflow-specific documentation for the empirical and theoretical components.

We have aimed to make the archive fully self-contained. In particular, we include all microdata inputs used in the empirical replication. We do so because  Kansas City Fed harmonized and longitudinally matched CPS is revised periodically. To ensure exact replication of the published results, we therefore bundle the specific vintage used in the paper together with the corresponding preprocessing and estimation code.

The empirical package reproduces the main empirical figures and the empirical appendix figures using the bundled CPS, macroeconomic, and external-instrument data. The theoretical package reproduces the quantitative model results using only the bundled code and configuration files. No confidential data are required for the documented replication workflows.

Please let us know if any additional clarification or reformatting would be useful for the archival review.
