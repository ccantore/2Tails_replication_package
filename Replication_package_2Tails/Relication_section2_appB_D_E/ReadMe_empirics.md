# Empirical Replication Package (`Replication_files_section2_appB_D_E`)

Replication material for the empirical analysis in Cantore et al. (2026), "A tail of labor supply and a tale of monetary policy" (Section 2; Online Appendix B, D, E).

## Software

- Matlab R2023b
- Stata/MP 18.5 (MP2)

## What Is Included

- `data/Raw_data/DataEstimation/` contains analysis-ready Matlab datasets (`.mat`) that allow reproducing the paper figures without re-downloading CPS microdata.
- `data/Raw_data/raw/` contains the macro/financial input spreadsheets used in the data-construction scripts.
- Plotting scripts save the paper/appendix figures as PDFs to `Output/` (created automatically if missing) with filenames matching `Manuscript/figures_final/`.
- CPS microdata are included in this package under `data/Raw_data/CPS/CEPR_ORG/` and `data/Raw_data/CPS/kansas/`. CEPR/Kansas-derived CSV extracts can be (re)generated via `data/Raw_data/CPS/RUN_ALL.do` (see "From Scratch" below).

## Controlled Randomness

All empirical estimation entry scripts set the random seed via `rng(1,'twister')` for reproducibility.

## One-Click Runner (Main + D/E Figures)

The package includes a single Matlab entry script:

- `run_empirical_replication.m`

This runner uses the datasets already included under `data/Raw_data/DataEstimation/`, executes the full main-text and D/E figure pipeline, and writes all PDFs to `Output/` (overwrite in place).

Usage:

1. Open Matlab.
2. Set the working directory to `Replication_files_section2_appB_D_E/`.
3. Run full mode (default):
   - `run_empirical_replication`
4. Optional fast mode (plots only; requires the precomputed result files expected by each figure block, such as `results.mat` and, where applicable, `priors_1.mat`):
   - `mode = 'fast'; run('run_empirical_replication.m');`

Scope of the one-click runner:

- Included: Figures 1-5, D1, D2, D4, D7, D8, E1.
- Excluded: `FigureA1_A2` and `FigureA3` (these require CEPR yearly CSV files generated by `data/Raw_data/CPS/RUN_ALL.do`).

## Optional: Rebuild Analysis Datasets from CPS Microdata ("From Scratch")

This is only required if you want to regenerate the analysis-ready `.mat` files under `data/Raw_data/DataEstimation/` starting from the original CPS sources.

### External Data Sources (Included Here; Links Kept for Re-Download)

1. CEPR CPS ORG extracts (1979-2019): uniform CPS outgoing rotation group (ORG) data extracts from CEPR.
   - Included in this package under: `data/Raw_data/CPS/CEPR_ORG/`
   - Website (optional re-download): <https://ceprdata.org/>
2. Kansas City Fed longitudinally matched CPS extract:
   - Included in this package under: `data/Raw_data/CPS/kansas/` (`CPS_harmonized_variable_longitudinally_matched_age16plus.dta`)
   - Website (optional re-download): <https://cps.kansascityfed.org/>
3. FRED-MD monthly macro database:
   - File used in this package: `data/Raw_data/raw/fred_md_new.xls`
   - Vintage used in this package: `FRED-MD 2021 M5`
   - Download source: <https://www.stlouisfed.org/research/economists/mccracken/fred-databases>
4. Excess bond premium (EBP) series:
   - File used in this package: `data/Raw_data/raw/ebp2.xls`
   - Source page: <https://www.federalreserve.gov/econres/notes/feds-notes/updating-the-recession-risk-and-the-excess-bond-premium-20161006.html>
   - Direct download CSV: <https://www.federalreserve.gov/econres/notes/feds-notes/ebp_csv.csv>

### Step A: Stata CPS Extraction (Single Entrypoint)

1. Confirm CEPR ORG `.dta` files are available in `data/Raw_data/CPS/CEPR_ORG/` and `CPS_harmonized_variable_longitudinally_matched_age16plus.dta` is available in `data/Raw_data/CPS/kansas/` (both are already included in this package).
2. Optional: re-download from CEPR/Kansas links above and replace local copies if needed.
3. Open `data/Raw_data/CPS/RUN_ALL.do` and set `global dir` once to the absolute path of your local `CPS/` folder.
4. In Stata, run `RUN_ALL.do` (from any working directory).
5. `RUN_ALL.do` automatically detects Windows vs macOS and sets the appropriate path separator (`\` or `/`). You do not need to edit path separators elsewhere in the code.
6. `RUN_ALL.do` automatically runs the CEPR and Kansas extraction scripts and writes:
   - CSV outputs in `data/Raw_data/CPS/ELABORATED DATA/` (e.g., `data_YYYY.csv`, `dataun_YYYY.csv`, `YYYY_zz.csv`)
   - Approximate running times of each called do-file are reported inside `RUN_ALL.do`.
7. Once the CEPR CSVs are present in `data/Raw_data/CPS/ELABORATED DATA/`, you can regenerate selected appendix figures:
   - Figure A1/A2: run `FigureA1_A2/extract_CEPR_Char.m` (writes `Output/char.pdf` and `Output/industry_by_wage_quintile_cepr_av_app.pdf`)
   - Figure A3: run `FigureA3/construct_aggregate.m` (writes `Output/ag_hours.pdf`)

### Step B: Kansas Fed CPS -> CSV

No additional command is needed if you already ran `data/Raw_data/CPS/RUN_ALL.do` in Step A.
For a Kansas-only rebuild, run `extract_data_kansas.do` from `data/Raw_data/CPS/kansas/` (it writes yearly `YYYY_zz.csv` files to `data/Raw_data/CPS/ELABORATED DATA/`).

### Step C: Matlab CPS Processing (Intermediate `.mat` in `data/Raw_data/CPS/ELABORATED DATA/`)

Run the relevant scripts in `data/Raw_data/CPS/MatlabCode/` to create intermediate `.mat` files in `data/Raw_data/CPS/ELABORATED DATA/` (e.g., `dataALL_*.mat`, `data_quant.mat`, `dataALLLevels_at2*.mat`, `dataALLGR.mat`, `dataALLFLOWS.mat`, `ind_wage_cepr.mat`, `educ_wage_cepr_all.mat`).

### Step D: Build Analysis-Ready `.mat` Files in `data/Raw_data/DataEstimation/`

Run the corresponding scripts in `data/Raw_data/`:

- Benchmark (Figure 1): `arrange_data_benchmark.m` -> `data_QUANT1.mat`
- Counterfactual (Figure 3): `arrange_data_counterfactual.m` -> `data_QUANT1_CF.mat`
- Alternative instrument (Figure D1): `arrange_data_allworkers_MPI.m` -> `data_QUANT1_MPI.mat`
- Full-time (Figure 4): `arrange_data_FT.m` -> `data_kansas_levels2_FT.mat`
- Growth/outflow (Figure 5): `arrange_data_Growth.m` -> `data_JOINTGR1.mat`
- Industry wage (Figure D4): `arrange_data_allworkers_ind_wage_cepr.m` -> `data_wage_ind_cepr.mat`
- Education wage (Figure D7): `arrange_data_allworkers_educ_wage_cepr_ALL_Categories.m` -> `data_wage_educ_cepr_all.mat`
- Levels robustness (Figure E1): `arrange_data_allworkers_by_LEVEL.m` -> `data_Atlanta_levels2.mat`
